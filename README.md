## Analytics Setup

The admin analytics dashboard uses server-only Google credentials and should be configured in `.env.local`:

```env
GOOGLE_SERVICE_ACCOUNT_JSON='{"type":"service_account","project_id":"...","private_key_id":"...","private_key":"-----BEGIN PRIVATE KEY-----\\n...\\n-----END PRIVATE KEY-----\\n","client_email":"...","client_id":"..."}'
GA4_PROPERTY_ID="123456789"
GSC_SITE_URL="https://example.com/"
```

Notes:

- Keep `GOOGLE_SERVICE_ACCOUNT_JSON` on one line and preserve literal `\\n` sequences in `private_key`; the server helper converts them back to real newlines.
- `GA4_PROPERTY_ID` should be the numeric GA4 property ID.
- `GSC_SITE_URL` must match the verified Search Console property exactly, including `https://` or `sc-domain:` where applicable.
- Do not prefix these variables with `NEXT_PUBLIC_`; they are used only on the server.
